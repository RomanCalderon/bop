## Out of scope (v1)

- User-uploaded photos
- In-app CSV import or export
- Per-user lists, public browse, or open signup
- Manual place entry (name/address form)
- Paste-a-Maps-link as a first-class add path
- Interactive seed picker or seed resolution mapping file
- City deletion
- Visited/unvisited, price, hours, or “open now”
- Mapbox / MapLibre / Supabase / a second map vendor
- Refreshing photo, rating, or Maps URL after insert
- Visual regression tests
- Live Google API tests in CI
- Load tests
- Soft-delete or audit log
- Optimistic locking for shared notes
- IP-restricting the server Google key
